# Decide where a venue or creator asks to be left off the public pages

## Goal
The public city page (`/<city>/<month>`, `views/highlights/CityHighlightView.svelte`, the "How we count" strip) names one way to ask to be left out, and someone watches it.

## Why
`human-docs/13` promises to honour a removal request the same day. The admin side exists (the city's do-not-list on Trends › Public highlights, then Rebuild), but a reader has nowhere to send the request, and the site has no contact page or address yet.

## Scope
- In: pick the channel; put it in the strip as a link; say in `human-docs/13` who watches it.
- Out: an automated form that edits the do-not-list (an admin's hand stays in the loop).

## Options
- A mail address on the domain (e.g. a `privacy@` or `hello@` inbox), linked as `mailto:`.
- A small public contact page with a Turnstile-protected form that notifies the admins on Telegram (`modules/telegram`).

## Open questions
- Which channel, and which address? Assumption until answered: a `mailto:` to an address the user names; nothing is published before it exists.

## Acceptance
- [ ] The strip links the channel; `human-docs/13` names it.
