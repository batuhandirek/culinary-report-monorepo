# Decide whether the front page's edition publishes itself or waits for an admin

## Goal
A recorded choice: the front page's live edition either goes live by itself every five days (today) or is built as a draft that an admin publishes, like the monthly Heat Check page.

## Why
The brand's guardrail says a piece naming venues or creators goes out only after an admin approved it, because a wrong match in public embarrasses a namesake. The user asked for the front page to update every five days by cron, so the edition publishes itself and the guardrail carries an exception. The code holds it to more instead (positive summaries and praise only reach the model, every number in a line is checked against what it was given, banned words and negatives fall back to plain sentences, paid and own posts never count, the do-not-list applies), and an admin can take an edition down at once. A wrong venue match can still name a place that was never posted about.

## Scope
- In: the choice, and if it is "admin approves": `build(cityId, now, { publish: false })` from the worker, a notice on Today ("A new front page is waiting"), the brand skill's exception removed.
- Out: changing what the edition counts.
