# Combobox copy is Turkish on English pages

## Goal
`ResponsiveMultiCombobox`, `ResponsiveCombobox` and `ComboboxList` take their search placeholder and empty text from
props (defaulting through `setUiLabels` / the UI label set of the page), so an English admin page shows "Search" and
"No results", not "Ara" and "Sonuç yok".

## Why
The admin's Terms tab (`TrendsTermsTab.svelte`) and the themes tab (`TrendsThemesTab.svelte`) use these controls; the
copy inside them is hard-coded Turkish while everything around it is English.

## Scope
- In: the props (`searchPlaceholder`, `emptyText`) with a default from the active UI labels; the two admin tabs pass
  nothing and read right; `/admin/ui-kit` shows the control with English copy.
- Out: any other hard-coded copy; a general i18n pass.
