# Read e-mail addresses from venues' websites (Impressum, Kontakt) for the sales list

## Goal
A prospect added to the sales list, and the brands on the Suggested prospects tab, show the e-mail address(es) found on the venue's website, so the salesperson can send the report after the call's "Can I e-mail it?" without hunting. Found addresses are suggestions on the venue; the prospect's `contactEmail` is still set by the salesperson.

## Why
Every business website in Germany carries an Impressum with an e-mail address (DDG §5, formerly TMG), and most have a Kontakt page. The venue row already holds the website from Google Maps. The outreach rule stays: no cold e-mail without consent (UWG §7); the address is for after consent, for the DM alternative, and for the report mail once won.

## Scope
- In: a plain fetch (no Apify; the favicon service's rules: 10 s timeout, size cap, public URLs only, platform profiles skipped) of the site's home page and its Impressum / Imprint / Kontakt / Contact links, `mailto:` links and e-mail patterns in text (with "[at]" / "(at)" de-obfuscation), stored as `Venue.contactEmails` (jsonb, with where each was found) and `contactsCheckedAt`; run for a brand's branches when a prospect is added and from a "Find contacts" button on the Sales tab; the prospect's details panel listing them with one-click "use". A phone found the same way is kept only when the venue has none from Google.
- Out: scraping Instagram bios (a paid actor), guessing addresses (`info@domain`), any automatic e-mail.
