# Root labels from the API

## Goal
No page holds a copy of the aspect vocabulary: `apps/frontend/src/lib/culinary.ts` `TOPIC_LABELS` (the nine root
labels) is deleted, and every API that sends a bare root key sends its label too (or the frontend reads it from data
already on the page).

## Why
The rule "pages read labels from the API, never from a copy of the vocabulary" (the aspects rule in
`domain-venues-and-reports`). Phase 3 moved every per-statement label onto the parts, but these still send keys only:
`AdminThemeInsightRowOutputDto` (the Trends themes tab's root pills), `AdminThemeInsightOutputDto.topic` (a theme page's
header), `PortalReviewFiltersOutputDto.topics[].topic` (the portal's review filter), and the report views without
`ReportData.aspects` (`ReportBranches`, `ReportPatterns`, `ReportReviewPlatforms`, `ReportAppendix`, the portal's
`PatternsView` / `TrendsView`) read `TOPIC_LABELS` for the roots.

## Scope
- In: a `roots: { key, label }[]` (or a label next to each key) on the three DTOs above, from `TopicIndex`; the report
  views taking root labels from `ReportData.aspects` (every aspect carries its `root`; add the roots themselves to
  `aspects` at build when missing); the frontend reading those; `TOPIC_LABELS` deleted; `svelte-check` clean; client
  regenerated.
- Out: any new page; labels for anything but the aspect roots.

## Pointers
- `apps/frontend/src/lib/culinary.ts`, the views named above, `apps/frontend/src/routes/(admin)/admin/trends/components/TrendsThemesTab.svelte`
- `apps/backend/src/modules/trends/dto/admin-theme-insights.dto.ts`, `services/theme-insight.service.ts`
- `apps/backend/src/modules/portal/dto/portal.output.dto.ts`, `services/portal.service.ts` (`facets`)
- `apps/backend/src/modules/reports/interfaces/report-data.interface.ts` (`aspects`), `services/report.service.ts`

## Acceptance
- [ ] `grep -rn TOPIC_LABELS apps/frontend/src` is empty; the themes tab, a theme page, the portal filter and a report
      built today show the same labels as before.
- [ ] A report built before `aspects` existed shows the key (as today), not a crash.
