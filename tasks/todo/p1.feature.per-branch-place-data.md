# Track and report every branch's place data, drop the "described branch"

## Goal
No branch stands in for a chain any more. Each figure is reported for what it belongs to: brand-wide figures (posts, reviews, press, comments, own accounts) across all branches, and place figures (busyness, open tables, search ranks, neighbourhood, rating trend, delivery and prices, Google details) for each branch on its own. The "Report's place figures" badge, "place figures: this one" and `described` are gone.

## Why
Today the most reviewed open branch in a city (`busiestBranch`, `BrandService.branchesIn(...)[0]`) is the only one whose place data is scraped and reported. Its busyness, search ranks and neighbourhood say nothing about the other branches, and the badge confuses whoever reads the brand page. A chain owner pays for every branch.

## Scope
- In:
  - **Pipeline** (`pipeline.service.ts`, the `described()` helper and `topBrands()[].venue`): `TRACK_SEARCH_RANKS`, `SAMPLE_BUSYNESS` (`DemandSampleCron`) and `SCRAPE_DELIVERY` take every open branch of the report brands. `SCRAPE_PRESS`, `SCRAPE_VENUE_SOCIAL`, `SCRAPE_COMMENTS` and `SCRAPE_OWN_ACCOUNTS` already search by the brand's name or account: make them brand-level (one search per brand), not "the described branch's". `SCRAPE_REVIEWS`, `REFRESH_VENUE_DETAILS` and `SAMPLE_RESERVATIONS` already cover every branch.
  - **ReportData** (`reports/interfaces/report-data.interface.ts`): the place sections move off `venue` into one entry per branch (`branches[]`: name, street, district, and that branch's busyness, demand, search ranks, neighbourhood, rating trend, prices, amenities), and a one-branch brand has a single entry. `ReportBranch.described` goes. Brand-level sections (`press`, `comments`, `ownAccounts`) say they are the brand's. `ReportSignalsService`, `ReportCityService`, `ReportReachService`, `summarizeReport` and the highlights prompt follow. Rebuild the dev reports afterwards.
  - **Report view** (`views/report/*`): place sections per branch (stacked, or a branch switcher on screen, all branches in the PDF). `ReportBranches.svelte` loses "place figures: this one".
  - **Portal** (`portal.service.ts` series and patterns, "the branch its newest report describes"): a branch picker for a chain's place charts.
  - **Admin**: `BrandBranchRow.svelte` badge, `BrandBranchesTab.svelte` `described` and its note, `BrandSignalsTab.svelte` "Place figures of", `BrandOverviewTab.svelte`, the brand page header's "(busiest place)" rating, `BrandListService`'s described branch.
  - Competitors: a branch-only competitor is compared with its branch, a brand-wide one with each branch's place figures where that makes sense.
- Out:
  - Outreach's phone and website for a chain (`busiestBranch` there picks a contact, not data): unchanged.
  - Grouping or summing place figures across branches (a mean of busyness indexes is meaningless: each is scaled to its own venue's peak).
  - A new report scope "one branch only": see the open questions.

## Acceptance
- [ ] A chain with three open branches in a city gets search ranks, busyness samples and delivery listings for all three in one monthly run (PGlite, actors mocked).
- [ ] Press, social search and comments run once per brand, not per branch.
- [ ] Its report holds one place entry per branch, and nothing in `ReportData` is called `described`.
- [ ] The report view and the PDF show every branch's place sections; the portal's place charts take a branch.
- [ ] The admin brand page shows no "Report's place figures" badge; the Signals tab picks any branch.
- [ ] Default step budgets checked against the extra branches. On dev, September 2026's 21 report brands have 28 open branches (5 chains, at most 3 branches), so the per-branch steps cost about a third more.
- [ ] `domain-venues-and-reports` skill rewritten where it says "the described branch" / "there is no main branch … most reviewed open branch".

## Open questions
- "Either all branches, or one specific branch": does an owner need a report that covers one branch only (a franchisee, say), as a third `Brand.reportScope`? Assumption: no. The brand's report covers every branch, and each place figure is shown per branch inside it.
- Busyness samples run twice a week, so they cost the most per branch. Assumption: sample every branch of a report brand, and cap it with the step budget like today.
