# Make `npm run backend:test` finish without running out of memory

## Goal
`npm run backend:test` runs every spec to the end on a dev laptop and prints Jest's totals.

## Why
The suite runs `--runInBand` with `--max-old-space-size=8192`; on 2026-10-24 it was killed by a V8 heap OOM after 70 passing files, so no task can show a green full run. Each PGlite spec boots its own in-process Postgres and the heap keeps growing across files in one process.

## Scope
- In: Jest config / the `test` script (e.g. `workerIdleMemoryLimit` with a small `maxWorkers`, or splitting PGlite specs into their own project), closing each spec's PGlite and app in `afterAll` where one leaks.
- Out: rewriting specs.

## Pointers
`apps/backend/package.json` (`test`), `apps/backend/jest.config.ts`, the PGlite test helper (`pglite-test` skill), `--detectOpenHandles` output.

## Acceptance
- [ ] A full `npm run backend:test` prints `Tests:` totals with exit 0.
