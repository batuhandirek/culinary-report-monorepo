# List Berlin's OSM checklist again and look up its unsearched places

## Goal
Berlin's checklist counts its places again (`coverage.listed` about 13,900) and the places no venue is have been searched on Google Maps, in one paid run or at the monthly pace, as the user decides.

## Why
Since 2026-11-02 Berlin's `osm_places_synced_at` (2026-11-02 06:00:20 UTC) is ahead of every place's `seen_at` (2026-10-21), so `OsmPlaceService.listed` returns nothing: coverage 0, no links, no lookups, and November's run searched none. `sync` now refuses an empty or halved answer (so it cannot happen again), but the stored state only heals when a sync lists the places: every listed place gets the new `seenAt`. The database with this state is the one the dev copy was cloned from, so it needs the fix deployed first.

What waits: 6,896 places unlinked and never searched (cafés 1,782, bars 642, pubs 695, biergarten 63, fast food 2,225, ice cream 241, food courts 9, bakeries 1,102, pastry 60, confectionery 77; all 4,728 restaurants are done). Searches go sit-down kinds first (`osmLookupOrder`), 2,000 a run at the $10 default: bakeries and pastry shops are reached in the fourth run (2 March 2027 if 2 December works). La Femme du Boulanger (`node/1718477871`, `shop=pastry` with `cafe=yes`) is place 6,764 of them.

## Scope
- In: after the fix is deployed, a sync of Berlin that lists its places; check `coverage` (`listed` about 13,900, `toLookUp` about 6,900).
- In: the lookups at the budget the user chose (open question), and a check that La Femme du Boulanger became a venue.
- Out: changing `osmLookupOrder` (a pastry shop tagged `cafe=yes` could go with the cafés; only worth it if the gap stays open for months).

## Pointers
- `apps/backend/src/modules/pipeline/osm-places/workflows/osm-places.workflow.ts` (`osm-places.month`: sync, plan, the `places.run` child, `saveLookups`); it runs on its schedule (the 2nd, 06:00 UTC) and when `lookup-venues` calls it. No controller starts it by hand, and a city's run for a period has one id (`operationRunId`), so a second run for the same month returns the first.
- `apps/backend/src/modules/venues/services/osm-place.service.ts` (`planLookups`: the budget is `stepBudgetsUsd.LOOKUP_OSM_PLACES`, default 10; 80 % of it at $0.004 a place)
