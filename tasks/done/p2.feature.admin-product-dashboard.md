# Make the admin overview show the product, not signups

## Goal
`/admin` shows: the last monthly run (status, when, duration, link to the pipeline), Apify spend this month against the credit, reports built for the current report month, mentions still unmatched, the outreach summary (stages, follow-ups due, outreach in the last 7 days), the top five suggested prospects by lead score, and the next cron date.

## Why
The overview counts users and sessions, and nobody signs up: the product is the pipeline and the sales list. The first question every morning is "did the run work, what did it cost, who do I write to today".

## Scope
- In: `GET /admin/overview` DTO with those numbers (each nullable so a failed query reads as "—"), the page with the number band and two lists (due follow-ups, suggested prospects).
- Out: charts, user counts (keep a link to `/admin/users`).

## Pointers
- `apps/frontend/src/routes/(admin)/admin/+page.svelte` (the band and skeleton pattern to keep).
- `apps/backend/src/modules/pipeline/controllers/admin.pipeline.controller.ts` (month cost SQL), `modules/outreach/services/outreach.service.ts` (`summary`), `modules/pipeline/crons/monthly-pipeline.cron.ts` (schedule).

## Acceptance
- [x] The page shows the numbers from the dev DB; a failed last run is red; due follow-ups link to the prospect.
