# Write the prospect's hook with an LLM when it is empty

## Goal
A prospect with no `hook` gets one sentence written from its latest report and lead signals, in the prospect's `language` ("The vegan meat decides 5 stars or fewer: leave it on the spit longer"), when it is added and on a "Suggest a hook" click; an admin can overwrite it.

## Why
`Prospect.hook` is "the one finding the first email leads with", typed by hand today. `PROSPECTS.md` shows a hook only works when it comes from the venue's own data (a complaint, a creator's video, a queue), and the report already holds exactly that. One short call per prospect.

## Scope
- In: `PitchHookAgent` (input: venue name and category, the latest report's `highlights`, the top complaint details and the lead signals; output: one sentence ≤ 25 words in the given language), called by `OutreachService.add` when `hook` is empty and by `POST /admin/outreach/prospects/:id/hook`; a button on the prospect page.
- Out: the whole outreach message (the templates are the outreach module's).

## Pointers
- `apps/backend/src/modules/outreach/services/outreach.service.ts` (`add`), `entities/prospect.entity.ts` (`hook`, `language`).
- `apps/backend/src/modules/reports/services/report.service.ts` (`latest`), `agents/report-highlights.agent.ts` (agent pattern).
