# Theme the review points the backfill skips because their review has no analysedAt

## Goal
Every stored review point has a theme, so every rebuilt report carries `reviews.praiseThemes` / `complaintThemes`.

## Why
After `POST /admin/feedback-themes/backfill` finished on dev (2026-10-22 06:45 UTC), 30 Google reviews (137 points, created 2026-10-15 to 10-19, all September, venues of Döner Pro, Choc-Spot and Nhas City Chicken) still had points without a `theme`. All 30 have `analysed_at` null, and `FeedbackThemeService.unthemedReviewIds` / `countUnthemedReviews` select `r.analysed_at is not null`, so the backfill never sees them and reports "nothing left". `countThemes` drops the theme counts of a set while any point lacks a theme, so those three September reports have none.

## Scope
- In: find why these reviews carry points but no `analysedAt` (an analysis path that writes points without stamping it, or rows from before the column); select unthemed reviews by their points, not by `analysed_at`, or stamp `analysedAt` where points are written; run the backfill on dev; rebuild the three September reports (admin Rebuild, two LLM calls each).
- Out: re-analysing reviews.

## Pointers
- `apps/backend/src/modules/venues/services/feedback-theme.service.ts` (`unthemedReviewIds`, `countUnthemedReviews`)
- `apps/backend/src/modules/venues/services/review.service.ts` (where `praise` / `complaints` and `analysedAt` are written)
- Check query: `select count(*) from reviews r, jsonb_array_elements(coalesce(r.praise,'[]') || coalesce(r.complaints,'[]')) p where not (p ? 'theme')`
- Tests: `social/tests/feedback-themes.pglite.spec.ts`

## Acceptance
- [x] PGlite: a review with points and no `analysedAt` is themed by the backfill (or can no longer exist). (`social/tests/feedback-themes.pglite.spec.ts`, "files the points of a review that has points but no analysedAt": failed before the fix, passes after)
- [x] The check query is 0 on dev, and the Döner Pro, Choc-Spot and Nhas City Chicken September reports carry theme counts after a rebuild. The check query is 0 for reviews and mentions (2026-10-22 11:15 UTC, after one backfill call: 30 reviews, 137 points). The rebuild is left to the per-branch session, which rebuilds all September reports once.
