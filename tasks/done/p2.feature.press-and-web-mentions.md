# Find press and web mentions of the venue each month

## Goal
Each month a Google News and web search for the venue's name (+ city) stores new articles and listicles (title, outlet, date, URL, a one-line LLM summary and whether it is a feature, a listicle or a passing mention); the report gets an "In the press" line and the lead score a "press" signal.

## Why
Press features drive guests the way creators do, and owners rarely know they were listed in "the 10 best brunch spots in Neukölln". It also catches listicles where competitors appear and the venue does not, which is an action ("pitch Mit Vergnügen's brunch list").

## Scope
- In: `WebMention` (venue, url unique, outlet, title, publishedAt, kind, summary), a `SCRAPE_PRESS` step over report venues with a small budget, the LLM classification in a batch, `ReportData.press`, the line in the report, the lead signal.
- Out: full-text archiving, paywalled outlets.

## Pointers
- Actors: https://apify.com/scrapewise/google-news-scraper ($2.50/1k articles), `apify/google-search-scraper` for web results.
- `apps/backend/src/modules/venues/util/venue-names.ts` (`isSameVenue` to drop namesakes), `venue-lead-score` task (signals).

## Acceptance
- [x] PGlite: mentions stored once per URL, classified; the report line lists the month's features (`venues/tests/web-mention.pglite.spec.ts`, `reports/tests/report-reach.pglite.spec.ts`).

## Open questions
- Budget: assume $3 default.
