# Let the owner pick their own competitors in the portal

## Goal
In the portal's Settings, the owner searches venues in their city and picks up to five competitors (with the suggestions from `competitor-auto-suggest` shown first); the next report compares against them, and the Trends charts draw them.

## Why
Nobody knows a venue's competition better than its owner, and a comparison the owner chose is one they believe. Today only an admin can set competitors.

## Scope
- In: `GET /portal/venues/:id/competitors` (+ suggestions), `POST` / `DELETE` through `VenueCompetitorService` behind `VenueAccessGuard`, a venue search endpoint limited to the venue's city and food categories, the settings UI with the cap of five and a note that the next report uses them.
- Out: competitors outside the city.

## Pointers
- `apps/backend/src/modules/venues/services/venue-competitor.service.ts`, `controllers/admin.venues.controller.ts` (the admin routes to mirror).

## Acceptance
- [x] An owner adds and removes a competitor; the sixth is refused; the admin page shows the same list. (PGlite `portal-explorers`; on dev a sixth answered 400 `too-many-competitors`.)

## Open questions
None.

## Log
- 2026-10-17: Decision: one competitor list per venue. Owner picks and admin picks are the same `VenueCompetitor` rows, edited through `VenueCompetitorService.add` / `remove`; a new `pickedBy` column (admin / owner / suggested, existing rows default `admin`) records who, and the portal labels "your pick" / "our pick". The cap of five (`MAX_COMPETITORS`, exception `TOO_MANY_COMPETITORS`) applies to every add, admin's included, since the report's comparison is built for a handful; the bulk fill already stops at five. An owner may only pick an open food venue of the venue's city; the admin path keeps its freedom. The fill skips any venue with competitors, so owner picks are never overwritten.
- 2026-10-17: Search (`/competitor-search?q=`) is name, street or district within the city, open food venues only, best known first; suggestions show while the list has room.
- 2026-10-17: Done. The admin Competitors tab does not show `pickedBy` yet (admin DTO untouched).
- 2026-10-17 (coordinator): the admin Competitors tab now shows who picked each competitor (`AdminVenueCompetitorOutputDto.pickedBy` on `listVenueCompetitors`, add and remove; "picked by the owner" / "added by the bulk fill" in the row).
