# Extract and match mentions after every recurring scrape, not only in the monthly run

## Goal
A post stored by a recurring scrape (the daily `SCRAPE_INSTAGRAM_RECENT`, and the weekly TikTok run `continuous-listening` adds) has its mentions extracted and matched within the day, so the brand list's current month, the Today page's "posts we couldn't place" and the brand pages see the month as it fills. The monthly run on the 2nd then extracts only what the last day brought.

## Why
`EXTRACT_MENTIONS` and `MATCH_MENTIONS` are free (gpt-5.4-mini, inside the daily allowance) but today run only inside `MONTHLY` or when an admin presses them. The daily cron (`InstagramRecentCron`) queues the scrape alone. Consequences: in-month data is invisible to the admin and the salesperson; the 2nd's run does a month of LLM work in one go (which is what ran the September run out of credits mid-way); the account matcher (part of `MATCH_MENTIONS`) also only runs monthly.

## Scope
- In: `InstagramRecentCron` queues `EXTRACT_MENTIONS` then `MATCH_MENTIONS` for the current month after the scrape run (same city, queued in that order: the queue runs oldest first, so they follow it); the same three-run pattern for the weekly TikTok run once `continuous-listening` lands (note it there); nothing changes in `MONTHLY` (its extraction finds little left to do).
- Out: scoring leads in the month (the score's window is the report month and the one before; a mid-month rescore would move the sales list on a half month); any paid step.

## Pointers
- `apps/backend/src/modules/pipeline/crons/instagram-recent.cron.ts` (`queueAll`), `apps/backend/src/modules/pipeline/services/pipeline.service.ts` (`queue`, `nextQueuedRunId`: oldest first)
- `apps/backend/src/modules/social/services/mention-extraction.service.ts` (`extract` takes every unanalysed post of the city, whatever its month), `mention-matching.service.ts` (`match`)
- Tests: `apps/backend/src/modules/pipeline/tests/instagram-recent.pglite.spec.ts` (one run per city with Instagram on: extend to three runs in order)
