# Share a report by a private link and see when it was opened

## Goal
An admin creates a link `/r/<token>` for a report. It opens the report with no login (the same `ReportView`) with a "Download PDF" button. The admin sees how many times and when it was last opened, and can revoke it.

## Why
The pitch is the venue's own report (`PROSPECTS.md`: "send #1–4 their own report"). A link opens on a phone where a PDF attachment does not, and the open event tells the user whether the owner looked at it, which is the signal to follow up (task `venue-outreach-status`). No account, no payment.

## Scope
- In:
  - `ReportShare` entity: report, `token` (22+ URL-safe random chars, unique), `createdBy`, `revokedAt`, `openCount`, `lastOpenedAt`.
  - `POST /admin/reports/:id/shares`, `DELETE /admin/reports/:id/shares/:shareId`, public `GET /reports/shared/:token` (the report DTO; counts an open) and `GET /reports/shared/:token/pdf`.
  - Frontend `routes/r/[token]`: no login, `robots: noindex, nofollow`, title with the venue and month; `ReportView` plus the PDF button; a 404 state for a revoked or unknown token.
  - Admin report page: a "Share" panel listing links with opens and a revoke action; copy-to-clipboard.
  - When the report's venue is a prospect, offer "Log as sent" next to the link: it creates an `OutreachTouch` (kind EMAIL or DM, the link in the body) through `OutreachService.log`.
- Out: passwords on links, expiry dates (revoke covers it), per-viewer analytics.
