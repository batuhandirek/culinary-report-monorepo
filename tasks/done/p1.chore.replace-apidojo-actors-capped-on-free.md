# Replace the apidojo actors, which return 10 items per run on Apify's Free plan

## Goal
TikTok searches (city and venue names), Instagram hashtags and TikTok comments come from actors that return as many items as the step asks for on Apify's Free plan. A run an actor cuts short because of the plan is visible on `/admin/pipeline`, not a silent success.

## Why
The account stays on the Free plan (never upgrade; the usage limit is $250 a month, so money is not the constraint). The apidojo actors restrict Free users: every run ends after 10 items with "Monthly run limit exceeded per user", the run still SUCCEEDS, and its status message says "Please subscribe to a paid plan". All 20 `apidojo/instagram-scraper` runs and both `apidojo/tiktok-scraper` runs in `apify_runs` returned exactly 10 items. So the Instagram scrape keeps ~50 posts a month instead of hundreds, the TikTok searches and venue-name searches see 10 videos per query, and comments are 10 per post. The top venues list, mention counts and the report's word of mouth all read from these posts.

## Scope
- In: the four calls of the three apidojo actors in `SocialScrapeService`:
  - `searchTikTok`, used by `scrapeCityTikTok` and by `scrapeVenueSocial` for venue names, on `apidojo/tiktok-scraper`.
  - `scrapeCityInstagram` on `apidojo/instagram-scraper` with tag URLs.
  - `scrapeComments` on `apidojo/tiktok-comments-scraper`.
- In: the item mappers for the new actors.
  - `SocialPostService.fromApidojo` and `fromInstagramHashtag`, and `fromApidojoComment` in `util/post-comments.ts`, become the new actors' mappers.
  - Keep `externalId` stable: `ig_<media pk>` for Instagram, the video id for TikTok. The new copies must stay the same rows as the posts already stored.
  - Keep subtitle links on TikTok items. Subtitles are downloaded while saving; the links expire within days.
- In: a Free-plan cap check in `ApifyService.runActor`. When a SUCCEEDED run's `statusMessage` asks for a paid plan, record it on the `ApifyRun` (e.g. in `error`) and log a warning. `/admin/pipeline` then shows the run as capped.
- In: the recorded cost of these runs. `apify_runs.cost_usd` says $0.000 for the apidojo runs, while Apify's `usageTotalUsd` says $0.005 each. Check that the new actors' costs are recorded.
- Out: upgrading the plan. Out: other actors (clockworks, compass, apify/*, scraping_solutions and signalbench all return full results on Free). Out: re-scraping past months.

## Candidates (Apify store, 2026-10-18, Free-tier prices)
- **TikTok comments:** `clockworks/tiktok-comments-scraper`.
  - $0.00125 a comment. Input `postURLs`, `topLevelCommentsPerPost`, `maxRepliesPerComment: 0`.
  - clockworks actors already work on Free here. Its per-post cap may allow one run for all posts if items name their post; check.
- **Instagram hashtags:** `apify/instagram-scraper`.
  - $0.0027 a post. `directUrls` of tag URLs, `resultsType: 'posts'`, `resultsLimit`, `onlyPostsNewerThan` (a date filter, unlike `apify/instagram-hashtag-scraper`).
  - ~5× apidojo's price: 20 hashtags × 100 posts ≈ $5.40, inside the step's $8.
  - Check whether items carry `inputUrl`. If so, one run can cover every hashtag.
- **TikTok search:** a region-filtered keyword search on Free is the open part.
  - `epctex/tiktok-search-scraper`: $0.0003 an item + $0.006 a query. Same inputs as apidojo's `keywords` / `dateRange` / `location` / `sortType`, but epctex may be the same publisher as apidojo, with the same restriction.
  - `novi/tiktok-search-api`: $0.0004 an item + $0.0025 a query. `keyword`, `region`, `publishTime`, `sortType`.
  - `clockworks/tiktok-scraper`'s search fails on device registration (domain skill).
- Verify each with one small paid run (≈30 items, the actor's minimum cap): it returns more than 10 items, `statusMessage` doesn't ask for a paid plan, and its fields map. The user approves paid runs.
